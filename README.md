# .github

Organization-level defaults for [**DiCompute**](https://github.com/DICOMPUTE).

| Path | What it does |
|---|---|
| [`profile/README.md`](profile/README.md) | Renders as the public org profile at [github.com/DICOMPUTE](https://github.com/DICOMPUTE) |
| [`SECURITY.md`](SECURITY.md) | Vulnerability disclosure policy |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | Contribution guidelines |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Community standards |
| [`SUPPORT.md`](SUPPORT.md) | Where to get help |
| [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE) | Default issue forms |
| [`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md) | Default PR template |

GitHub applies each file to every repository in the organization that does not
ship its own copy. A repository-local file always wins — so repos with their own
templates keep them.

This repository is public so the org profile renders for everyone. It contains
documentation only: no source, no configuration, no secrets.
